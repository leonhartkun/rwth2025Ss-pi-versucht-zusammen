Detailed Description

Repräsentiert eine Zeitschrift als spezielles Medium.

Die Klasse Magazin erweitert die abstrakte Basisklasse Medium um das Ausgabedatum und die Sparte (z. B. Wissenschaft, Sport, Mode).

Verleiht das Magazin, falls es noch nicht ausgeliehen ist.

Versucht, das Magazin zu verleihen.

Magazine sind normalerweise nicht ausleihbar. In der Standardumsetzung kann dies entsprechend angepasst oder eingeschränkt werden.

Parameters
personDie ausleihende Person.
ausleihdatumDas Datum der Ausleihe.
Returns
true, wenn die Ausleihe erfolgreich war; sonst false.

Magazine, die am selben oder vorangehenden Tag erschienen sind (also neueste Ausgabe), dürfen nicht ausgeliehen werden. Wenn das Erscheinungsdatum mindestens 1 Tag zurückliegt, wird die Standard-Ausleihlogik von Medium verwendet.

Parameters
personDie Person, die das Magazin ausleihen möchte.
ausleihdatumDas gewünschte Ausleihdatum.
Returns
true, wenn die Ausleihe erlaubt und erfolgreich ist; false, wenn die neueste Ausgabe gesperrt ist.
